# Input tables for the 2D saline-aquifer example

These are the existing H2store illustrative-case inputs by Elyes Ahmed / SINTEF Digital (2024). The deck retains its original copyright and attribution. This compact bundle contains only the Eclipse deck and files it includes; the grid, rock regions, initial state, and cycle schedule are generated by `modelForSimple2DAquifer`.

Source: the public [MRST H2storage dataset](https://www.sintef.no/contentassets/124f261f170947a6bc51dd76aea66129/h2storage.zip), preserved from the existing H2store input distribution. The example accompanies Ahmed et al., *Phase behavior and black-oil simulations of hydrogen storage in saline aquifers*, Advances in Water Resources 191 (2024), 104772.

`RS_PVT_H2STORAGE.inc` tabulates hydrogen dissolution in pure water. The liquid phase is represented as the MRST oil phase. This input is the zero-added-salt member of the saline-aquifer model family; it must not be labeled as a high-salinity simulation. Diffusion is disabled in this deck. The bundled data are model inputs, not simulation results.
